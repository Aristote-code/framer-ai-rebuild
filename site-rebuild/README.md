# Rebuilt site — 14 route(s)

A clean, editable rebuild of 14 page(s) from https://framer-ai.com, generated by
`extract-site` and composed into one navigable site.

**This is a copy of someone else's site**, produced for development and fidelity
comparison. It ships `noindex`/`nofollow` three ways — a meta tag in
`index.html`, a `Disallow: /` `robots.txt`, and an `X-Robots-Tag` header via
`public/_headers` — so it is never indexed as though it were the original.
Don't remove those.

`public/_redirects` is load-bearing, not cosmetic: the router is history-based,
so without the SPA fallback every deep link 404s on refresh.

## Run

```bash
bun install
bun run dev     # http://localhost:5173
bun run build   # -> dist/
```

## Layout

- `src/pages/<slug>/` — one lazily-loaded route each: `page.tsx`, `sections/`,
  `content/`, `data/`, and its own CSS. Editing a section file hot-reloads.
- `src/App.tsx` — a small history router that intercepts internal links.
- `src/NavDropdowns.tsx` — hover mega-menus. Framer mounts these on hover, so
  they don't exist in a static capture; they come from
  `extract-site capture-nav` and are shared across every route.
- `public/` — localized images, videos and fonts.

## Known limits

- **Desktop only (1440px).** No responsive rules are generated; at narrow
  widths you get the desktop layout clipped.
- Continuously-animating components sit at whatever phase they were captured
  in, so they won't match the original frame-for-frame.
- Hover transitions use a 0.2s default — Framer's real timing is JS-driven and
  isn't visible to the capture.
